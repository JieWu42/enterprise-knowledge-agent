# 轻量同义词扩展与检索对照

在基础验收之外，追加一轮可解释的检索改进：用领域词表帮助口语表达找到制度原文，提供关闭开关和实际对照结果。保留原字符片段检索，不增加向量服务或第三方依赖。

## 改动

[领域词表](../data/retrieval_aliases.json)将“出国”扩展为“境外”、“交账”扩展为“报销”、“笔记本”扩展为“办公电脑”等。扩展仅用于候选召回和排序，原问题保留；模型继续根据实际原文判断适用范围与答案，词表不包含问题到答案或问题到文档 ID 的映射。

保留原始查询字符二元片段，新增词产生的片段按 0.5 权重计分，重复片段不重复加分。新增词对最佳段落选择和文档排名生效。search_documents 的 applied_aliases 明确展示应用了哪些词；Trace 的 retrieval_config 记录开关、权重和词表 SHA256。已知编号、摘要或扩展词均不授权引用，仍需成功读取原文。

命令行 --no-query-expansion 关闭扩展，便于复现原基线。关闭后排名与改动前保留的基线逐条一致，见 [controls.json](../examples/retrieval-improvement/comparison/20261030T202807Z_6d2e8548/controls.json)。

## 固定问题与实际结果

先保存 [12 条开发问题及相关文档标注](../data/retrieval_eval.json)，运行 [原实现基线](../examples/retrieval-improvement/baseline-snapshot/20261030T202713Z_3167f91e/summary.json)，再实现扩展。两次问题文件 SHA256 均为 8d8974561a733ecf250bedd1e56e514927d400baa75bd16c875d6038eb3d79a4，没有替换问题来美化结果。

| 文档级检索指标 | 原字符片段基线 | 同义词扩展 |
| --- | --- | --- |
| Hit@1 | 7/12，58.3% | 11/12，91.7% |
| 宏平均 Recall@3 | 79.2% | 100.0% |
| MRR@8 | 0.6806 | 0.9583 |

指标定义：Hit@1 为首位候选属于相关文档集合的问题比例；每题 Recall@3 为前三位覆盖的相关文档数除以该题标注相关文档总数，再对问题平均；MRR@8 为前八位中第一个相关文档排名倒数的平均，未命中计 0。冲突问题将两份相关制度都计入相关集合，避免只找到一份就视为召回完整。

完整逐题排名见 [baseline.json](../examples/retrieval-improvement/comparison/20261030T202807Z_6d2e8548/baseline.json)、[expanded.json](../examples/retrieval-improvement/comparison/20261030T202807Z_6d2e8548/expanded.json)及[汇总](../examples/retrieval-improvement/comparison/20261030T202807Z_6d2e8548/summary.json)。其中“出国办事回来，交账最晚能拖几天”由无匹配变为境外差旅办法首位；“请年休假走哪个入口”由无匹配变为请假流程首位。

R01“国内出差结束了，费用单据最迟什么时候交”仍将境外办法排在首位，境内办法在前三位，未对该问题继续特调至满分。后续仍需模型阅读适用范围；不能直接把排名第一当成答案。

## 端到端回归

扩展后 [24 项工程测试](../examples/test-results/20261030T202808Z.json)通过，包含口语召回、关闭扩展、未读来源不得引用等检查。[17 项真实模型用例](../examples/retrieval-improvement/real-model/20261030T202847Z_1e53c7ad/summary.json)的自动断言通过：原有 15 项全部保留，新增出国出差交账、笔记本开不了机两项口语问法。

新问题的实际结果为：境外报销回答 45 个自然日并引用境外办法；办公笔记本故障回答通过 IT 工单报修并引用设备故障制度。模型可能自行把口语改写为规范查询，因此这两条运行只证明端到端功能，没有单独证明词表对模型最终答案的因果贡献。

## 复现

```powershell
# 不调用模型，比较两种检索方式。
python scripts/retrieval_benchmark.py

# 对同一个问题关闭扩展运行。
python run.py --question "出国出差回来，最晚什么时候交账？" --no-query-expansion

# 当前真实模型回归，共 17 项。
python scripts/evaluate.py --mode real
```

## 限制与取舍

这是 8 份合成资料、12 条可见开发问题上的文档级检索实验，不是独立盲测、问答准确率或生产效果。词表和测试面向相同领域，存在开发集适配；后续应增加由他人编写的未见问法。

“饭钱”“垫付”等词不保证与“工作餐”“报销”严格等义，扩展可能引入无关候选。候选召回不代表用户已经符合制度条件，仍由模型读取适用范围、处理冲突并在不足时追问。

轻量方案的优点是成本低、可关闭、可审计；不足是人工维护和领域依赖。若资料规模增长，应先在独立问题集上比较分词检索、向量或混合方案，再决定是否增加依赖。
